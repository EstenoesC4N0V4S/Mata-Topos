# 🐹 Mata Topos

Juego arcade desarrollado con **HTML5, CSS3 y JavaScript**, inspirado en los clásicos juegos de reacción rápida y con una estética retro y colorida.

El objetivo es sencillo: **¡golpea a los topos antes de que desaparezcan y consigue la mayor puntuación posible!** 🎮

## 🎮 Cómo jugar

1. Pulsa el botón **Jugar** para comenzar.
2. Los topos aparecerán aleatoriamente por el tablero.
3. Haz clic sobre ellos lo más rápido posible.
4. Cada topo eliminado suma puntos.
5. **El juego no tiene un tiempo límite ni un final establecido**, por lo que puedes seguir jugando y aumentando tu puntuación mientras quieras.
